# Night Bloom

Night Bloom is a cozy-horror greenhouse simulation. Tend plants through day and night, balance moisture and feeding, and respond to stress events.

## Run

Open `project.godot` in Godot 4.x and press Play. Controls: **W** water, **F** feed, **N** toggle night, **R** restart.

## Project files

- `Main.gd`: plant state, day/night cycle, stress events, and bloom behavior.
- `Main.tscn`: greenhouse scene and HUD.

## Requirements

Godot 4.x. No environment variables or external services are required.
